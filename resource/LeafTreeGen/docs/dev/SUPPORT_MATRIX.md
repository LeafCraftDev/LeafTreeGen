# LeafTreeGen (TreeGen) Support Matrix

Canonical platform and Minecraft version compatibility matrix for **LeafTreeGen (`TreeGen`)**.

---

## Minecraft Version & Platform Compatibility (1.20.x – 26.3)

**LeafTreeGen (`TreeGen`) supports Minecraft `1.20.x`, `1.21.x` (`1.21.1`–`1.21.11`), `26.1`, `26.2`, and `26.3`** across Paper, Folia, Spigot, Purpur, Fabric, and NeoForge.

| Platform / Loader | Supported Minecraft Versions | Java Requirement | Capabilities | Status |
|---|---|---|---|---|
| **Paper / Purpur / Pufferfish** | `1.20.x`, `1.21.x`, `26.1`, `26.2`, `26.3` | Java 17 / 21+ | Procedural species generation (`generation-mode`), custom saplings (`sapling-drop-chance`), `/leaftree test` | **Tier-1 Supported** |
| **Folia** | `1.20.x`, `1.21.x`, `26.1`, `26.2`, `26.3` | Java 21+ | Region-scheduled canopy/trunk placement with zero main-thread chunk loads (`S-005`) | **Tier-1 Supported** |
| **Spigot / Fabric / NeoForge** | `1.20.x`, `1.21.x`, `26.1`, `26.2`, `26.3` | Java 17 / 21+ | `/leaftree`, `/treegen`, custom species YAML definitions | **Supported** |
